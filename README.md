## What is Sonar?

Sonar is building open-source observability infrastructure for AI agents.

As AI agents become more autonomous, understanding their behavior becomes essential. Sonar aims to make agent execution transparent, traceable, and easier to debug.

### Our Mission

Make AI agents observable, understandable, and trustworthy — through open-source tooling.

### What We're Building

- **Tracing** — Understand agent execution flows.
- **Monitoring** — Track agent behavior and performance.
- **Debugging** — Investigate failures and unexpected decisions.
- **Observability** — Gain visibility into AI agent systems.
- **Open Source** — Build in the open, together.

### Why Sonar?

AI agents shouldn't be black boxes.

We believe developers deserve the tools to understand what their agents are doing, why they're doing it, and where things go wrong.
